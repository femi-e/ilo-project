======================================================================
WHAT THE 4B NEEDS TO DO
======================================================================
1. Parse each message: extract role, content preview, length
2. Score each message 0.0-1.0 for relevance to the latest user query
3. Extract entities and claims from the conversation
4. Return:
   {
     chunk_scores: { "0": 0.95, "1": 0.90, "2": 0.85, ... },
     extracted_entities: [ { name, type, confidence, tags } ],
     extracted_claims: [ { subject, relationship, object, category, confidence } ]
   }

======================================================================
SCORING RULES
======================================================================
- Score 0.0 = drop this chunk entirely
- Score 1.0 = essential, must keep
- Score < 0.5 = eligible for eviction when over budget
- Always keep: last 2 messages (current query + previous assistant)
- Budget: 80,000 tokens (40% of 262K model window)
- Eviction: drop lowest-scored chunks until under budget
